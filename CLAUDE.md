# Памятка для ассистента (ukraine-tv.uk)

Сайт генерируется: **правьте источники, не HTML**. После правок: `python3 tools/build.py` дважды (второй раз должно быть `written/changed: 0`).

## Где что менять
- Каналы: `data/channels.json` + `tools/texts.py` (названия, слоганы, «о канале», uk/en/ru). См. docs/CHANNELS.md.
- Тексты интерфейса: `tools/i18n.py`; главная/категории/страны/блог: `tools/home_i18n.py`, `tools/countries.py`, `tools/blog.py`; about/privacy/advertising — словарь `STATIC` в `tools/build.py`.
- Верстка: `assets/site.css`, `home.css`/`pages.css` (генерируются `tools/make_ref_css.py` из CSS эталона — вручную не править), JS главной — `assets/home.js`.
- Согласие и реклама: `assets/gate.js`, `assets/ads.js`, встроенная страховка `gate_guard()` в `tools/build.py`.
- После правки `assets/*.js|css` поднимайте `ASSET_V` в `tools/build.py`.

## Правила
- Один `<h1>` на странице; JSON-LD должен парситься; внутренние ссылки не должны быть битыми (проверка — скрипт в docs/OPERATIONS.md, раздел «Проверки перед пушем»).
- Никаких обещаний «HD» в текстах: качество зависит от источника.
- Названия сервисов аналитики в тексте баннера согласия не указывать (по решению владельца); в политике конфиденциальности они указаны.
- Секреты (токены Telegram/Cloudflare) в репозиторий и в чат не вставлять. Токены живут в `.env`/`.cf.env` владельца (в `.gitignore`).
- Коммиты в `main` и любые необратимые действия (удаление воркеров, смена DNS) — только после явного подтверждения владельца.
- Коммит-сообщения заканчивать строкой `Co-Authored-By: …`, если её требует окружение.
