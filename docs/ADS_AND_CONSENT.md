# Согласие на cookie и реклама

## Окно согласия — `assets/gate.js`
- Блокирующее окно по центру экрана: «Погоджуюсь» / «Не погоджуюсь» (uk/en/ru).
- «Погоджуюсь» → в `localStorage` ключ `utv_consent=granted`, загружаются GA4 и Clarity (идентификаторы в начале `gate.js`) и реклама (`ads.js` ловит событие `utv-consent-granted`).
- «Не погоджуюсь» → `utv_consent=denied`, весь контент страницы удаляется, остаётся заглушка «Доступ до сайту закрито» с кнопкой «Передумав — погоджуюсь» (после неё страница перезагружается). Закрыть вкладку скрипт не может, поэтому заглушка.
- Повторный вход с `denied` — снова заглушка. Ссылка «Налаштування cookie» в футере (`data-utv-prefs`) открывает окно заново.
- **Защита от скрытия окна:** скрипт каждые 3 секунды проверяет, что окно в DOM и видимо; если его скрыли или удалили (блокировщик, DevTools) — страница закрывается запасной заглушкой `#utv-hl`. Дополнительно во `<head>` каждой страницы стоит встроенная страховка (`gate_guard()` в `tools/build.py`): если `gate.js` не выполнился за 2,5 с после загрузки, а согласия нет — та же заглушка.
- Поисковые роботы и превью ссылок (Googlebot, Bing, Yandex, Telegram, Lighthouse…) окно не видят — регулярное выражение по User-Agent в `gate.js` и в страховке.
- Идентификаторы и названия файлов нейтральные (`gate`, `utv-gate`): блокировщики скрывают всё со словами `cookie`/`consent`.

> Юридическая заметка: «согласие или уход» (cookie wall) не считается добровольным согласием по GDPR для посетителей из ЕС и Великобритании. Смягчённый вариант: при отказе открывать сайт без рекламы и аналитики (в `lock()` вместо заглушки сохранять `denied` и не грузить скрипты).

## Реклама — `assets/ads.js`
Грузится только после согласия. Выключатели: `ADS_ENABLED = false` в файле, `?noads=1` в адресе.

| Сеть | Формат | Настройка |
|---|---|---|
| **Monetag** | In-Page Push, все страницы, через 20 с после согласия | `MONETAG = { zone: '11258077', src: 'https://nap5k.com/tag.min.js' }` — зона «Luminous tag» сайта `ukraine-tv.uk` (id сайта в кабинете 3401185) |
| **Adsterra** | баннер 300×250 в блоках `.ad-slot` (главная и страницы каналов: над программой передач и под «Популярными каналами») | `ADSTERRA = { key, src, width, height }` — взять из кода баннера в кабинете Adsterra; пока ключи пусты, блок скрыт |

Баннер вставляется в `iframe srcdoc` (код Adsterra использует `document.write`). Блоки `.ad-slot` выводит `build.py` (главная, `channel_page`); CSS — в конце `assets/site.css`.

### Как добавить баннер Adsterra
1. В кабинете Adsterra добавить сайт `ukraine-tv.uk`, создать Banner 300×250, скопировать код (`atOptions` с `key` и ссылка `…/<key>/invoke.js`).
2. Вписать `key`, `src`, размер в `ADSTERRA` (`assets/ads.js`), поднять `ASSET_V`, `python3 tools/build.py`, запушить.
3. Проверить в окне без блокировщиков: «Погоджуюсь» → блоки справа от плеера заполнились.

### Проверка
- Открыть сайт в чистом профиле без расширений → окно по центру → «Погоджуюсь» → через ~20 с срабатывает Monetag; статистика зоны в кабинете Monetag (Statistics) появляется с задержкой.
- `?noads=1` — без рекламы. Без согласия реклама не загружается.

### Страница для рекламодателей и политика
`/advertising/` (uk/en/ru) и `/privacy/` — тексты в словаре `STATIC` в `tools/build.py`; в политике упомянуты Monetag и Adsterra.
